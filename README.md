# WhatsApp Chat Viewer (Mobile-First)

An interactive, responsive WhatsApp chat viewer with dark/AMOLED/light themes, offline search, analytics, and password protection.

## Features
- **Mobile-First WhatsApp UI**: Authentic bubbles, curved tails, double blue ticks, and date separators.
- **Password Protected**: Encrypted client-side access.
- **⭐ Starred Messages**: Save and browse bookmarked messages.
- **📊 Chat Analytics**: Streaks, busiest day, word counts, top emojis, and hourly/weekday bar charts.
- **🔍 Quick Sender Filter**: Filter messages by sender (`All` / `You` / `Prachi`).
- **🌓 3 Themes**: Dark Mode, AMOLED Pure Black, and Classic Light Theme.
- **⚡ Instant Search & Date Jump**: Fast in-conversation text search and calendar date jump.
- **Zero Dependencies**: Pure HTML/CSS/JS that runs 100% offline.
